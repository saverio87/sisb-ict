# Atomic Visual: IP address = a device's unique ID

## Specifications
- **Lesson**: P4, Week 4, Computer Systems
- **Concept**: IP address as a unique device identifier
- **Atomic purpose**: After seeing this, students will understand that an IP address is a unique number that identifies a device on a network, like a street address or name badge.
- **What this image is NOT about**: How IP addresses are assigned, technical IP protocols, or network configuration.
- **Challenge lens**: Abstract entity — "IP address" sounds technical and needs a concrete mental model.
- **Audience**: P4 (9–10 years old), mixed ability, some EAL learners
- **Aspect ratio**: 4:3 landscape for slides

## Visual description
Three devices arranged in a row: a laptop on the left, a smartphone in the middle, and a tablet on the right. Each device has a small name badge (like a conference name tag) attached to it. The badges show different IP addresses in bold text: the laptop shows "192.168.1.1", the phone shows "192.168.1.2", and the tablet shows "192.168.1.3". The badges are brightly coloured (coral, sky blue, mint green) to make them stand out. The devices are friendly cartoon shapes with rounded corners. The background is clean white.

## Text in image
- "192.168.1.1" on the laptop's badge
- "192.168.1.2" on the phone's badge
- "192.168.1.3" on the tablet's badge
(These are essential to show that each device has a unique address)

## Style
Friendly flat-vector cartoon style. Bright primary palette: sky blue (#4A90E2) for the laptop, coral (#FF6B6B) for the phone, mint green (#6BCB77) for the tablet. Name badges in contrasting bright colours. Clean white background. Rounded shapes, soft shadows, approachable cartoon aesthetic.
