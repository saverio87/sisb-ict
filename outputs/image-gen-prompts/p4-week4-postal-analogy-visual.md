# Atomic Visual: The postal analogy — packets travel like stamped letters

## Specifications
- **Lesson**: P4, Week 4, Computer Systems
- **Concept**: Data packets are like a large file split into stamped envelopes
- **Atomic purpose**: After seeing this, students will understand that a large file is split into smaller packets, each with a destination address, like a book split into stamped pages.
- **What this image is NOT about**: How the internet works technically, what happens during transmission, or any postal service details beyond the analogy.
- **Challenge lens**: Invisible process — students need to see the mapping between digital files and the postal analogy.
- **Audience**: P4 (9–10 years old), mixed ability, some EAL learners
- **Aspect ratio**: 4:3 landscape for slides

## Visual description
Left side: A large, friendly-looking book (cartoon style, with a simple cover design) sits on a surface. A large curved arrow points from the book toward the right side. Along the arrow's path, the book is shown being split into 4–5 smaller envelopes (like mailing envelopes). Each envelope has a small stamp in the corner and an address label. The envelopes are flowing along the arrow toward a simple mailbox on the right side. The mailbox is a classic red post box shape. The background is clean white.

## Text in image
None — the visual shows the transformation from book to envelopes to mailbox, no text needed.

## Style
Friendly flat-vector cartoon style. Bright primary palette: sunny yellow (#FFD93D) for the book, coral (#FF6B6B) for the envelopes and mailbox, sky blue (#4A90E2) for the arrow and stamps. Clean white background. Rounded shapes, soft shadows, approachable cartoon aesthetic.
