# Atomic Visual: What is a data packet?

## Specifications
- **Lesson**: P4, Week 4, Computer Systems
- **Concept**: Data packet
- **Atomic purpose**: After seeing this, students will understand that a data packet is a small piece of data with a destination label attached.
- **What this image is NOT about**: How packets are routed, what's inside the data, how the internet works, or any technical protocols.
- **Challenge lens**: Abstract entity — students have never seen a packet and need a concrete mental model.
- **Audience**: P4 (9–10 years old), mixed ability, some EAL learners
- **Aspect ratio**: 4:3 landscape for slides

## Visual description
A small cardboard parcel box (about the size of a shoebox) sits in the centre of the image. On top of the box is a large, clearly visible sticky label (like a shipping label). The label shows a simple address format: "TO: 192.168.1.5" in bold black text. From inside the open top of the box, a small glowing file icon (like a document or photo) is peeking out, suggesting the box contains data. The box has a friendly, approachable look with rounded corners and soft shadows. The background is clean white or very light grey.

## Text in image
- "TO: 192.168.1.5" on the shipping label (this is essential to show what a destination address looks like)

## Style
Friendly flat-vector cartoon style. Bright primary palette: sky blue (#4A90E2) for the file icon glow, coral (#FF6B6B) for the sticky label, sunny yellow (#FFD93D) for highlights. Clean white background. Rounded shapes, soft shadows, no harsh edges. Kid-friendly but not babyish.
