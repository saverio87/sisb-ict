# Atomic Visual: The packet's journey — Chromebook → Router → Gateway → Cloud Server

## Specifications
- **Lesson**: P4, Week 4, Computer Systems
- **Concept**: The path a packet takes from device to cloud server
- **Atomic purpose**: After seeing this, students will understand the exact path a packet takes: Chromebook → Local Router → IP Gateway → Cloud Server.
- **What this image is NOT about**: What happens at each step, technical details of routing, or what's inside the cloud server.
- **Challenge lens**: Multi-step procedure — students need to see the sequence and direction of data flow.
- **Audience**: P4 (9–10 years old), mixed ability, some EAL learners
- **Aspect ratio**: 4:3 landscape for slides

## Visual description
A horizontal journey map with 4 landmarks arranged left to right. Far left: A friendly cartoon Chromebook (laptop shape, simple and recognisable). Next: A small Wi-Fi router (box with antennae). Next: A larger gateway box (more substantial than the router, like a server rack). Far right: A large cloud-shaped server (fluffy cloud shape with server lights or indicators). Between each landmark, a large curved arrow points from left to right, showing the direction of travel. Small packet boxes (coral-coloured) are shown travelling along the arrows. The background is clean white.

## Text in image
None — the visual shows the sequence and direction, no text labels needed.

## Style
Friendly flat-vector cartoon style. Bright primary palette: sky blue (#4A90E2) for the Chromebook and cloud, coral (#FF6B6B) for the packets, mint green (#6BCB77) for the router, slate grey (#5A5A72) for the gateway. Clean white background. Rounded shapes, soft shadows, approachable cartoon aesthetic.
