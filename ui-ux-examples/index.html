UI / UX — Good vs Bad

Four real examples. Can you spot which part is the UI and which part is the UX?

Example 1
Good UI & Good UX
A polished finance dashboard. Clear contrast, logical layout, and a safe 2-step confirmation before transfers.
 Example 2
Bad UI & Good UX
A 1998-style logistics terminal. Looks plain, but the search, keyboard shortcuts, and validation work brilliantly.
 Example 3
Good UI & Bad UX
A luxury checkout page. Gorgeous design — but the text is unreadable, the price is hidden, and the pay button needs a 5-second hold.
 Example 4
Bad UI & Bad UX
An event registration form. Neon colours, a giant "Confirm" button that actually resets the form, and a tiny hidden submit at the bottom.
